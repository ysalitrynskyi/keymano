# Edit a `.keylayout` online

Use the hosted web app when you need to inspect or fix a macOS keyboard layout without installing desktop software.

- Open a `.keylayout` file with **Open…** or drag it into the page.
- Edit keys, modifiers, dead keys, and bundle export settings locally in the browser.
- Validate before download.
- Save as `.keylayout` or export a `.bundle.zip`.

Your layout content stays in the browser; Keymano has no account or upload requirement.
