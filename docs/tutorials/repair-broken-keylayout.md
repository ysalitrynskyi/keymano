# Repair a broken `.keylayout`

Use this when macOS refuses to load a layout or a downloaded file behaves strangely.

1. Open the `.keylayout`, `.bundle`, or `.bundle.zip`.
2. Go to **XML & Validation**.
3. Review the installability score and grouped issues.
4. Open **Repair preview** to see what Keymano will change.
5. Click **Auto-repair** only if the preview matches your intent.
6. Save a copy with **Save As…** before replacing the original.

Common auto-repairs include missing special key outputs, invalid ids, bad keymap bases, and JIS map fixes.
