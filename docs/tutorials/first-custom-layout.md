# First custom layout

Goal: start from the standard U.S. map, change a few keys, validate, then save.

1. Open Keymano and choose **Guided start → Tweak U.S. QWERTY**.
2. In **Editor**, click a key. Use **Edit output** or double-click the key.
3. Type the new output. Multi-character output is allowed, but keep macOS limits in mind.
4. Toggle **Shift**, **Option**, or other modifiers to edit another layer.
5. Open **XML & Validation**. Fix any reported issues before installing.
6. Use **Save As…** for a `.keylayout`, or **Bundle → Export** for a `.bundle`.

Tip: use **Quick Entry** when you want to fill many keys in visual order.
